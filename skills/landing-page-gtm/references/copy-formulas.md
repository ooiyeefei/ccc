# Copy Formulas

Proven patterns for landing page copy. Pick and adapt to context.

## Headline Formulas

### Pain-First Headlines
- "Stop [painful action] — [product] handles it"
- "Every [time period] you [don't act], another [loss happens]"
- "[Painful thing] is costing you [what they lose]"

### Outcome-First Headlines
- "[Desirable outcome] — without [thing they hate]"
- "The only [category] that [unique differentiator]"
- "[Product] that gets [better metric] every [time period]"

### Competitive Headlines
- "Every [category] claims [buzzword]. [How you're different]."
- "Not [old way]. [New way] that [outcome]."
- "[Category] built for [year], not [past year]."

### Urgency Headlines
- "Your competitors are already [doing the thing]"
- "Every [time unit] you wait, [loss continues]"
- "[X customers] switched this month. Here's why."

## Feature Card Patterns

### The "Snap" Pattern (instant gratification)
```
[Action verb] a [thing]. Done.
AI [does the work]. [Handles edge case].
[Outcome] — [eliminates negative].
```
Example: "Snap a receipt. Done. AI reads every line, sorts it to the right category. No spreadsheets, no month-end panic."

### The "Not Like Others" Pattern (differentiation)
```
Every [category] claims [thing]. Most just [weak version].
[Product] is different. [How it actually works].
[Concrete metric or behavior]. [Outcome].
```
Example: "Every finance app claims AI. Most just match keywords. Ours studies your corrections and gets smarter every week."

### The "Never Again" Pattern (pain elimination)
```
Stop [painful action] [frequency].
[Product] handles it — [how], [speed], [scale].
[Short outcome sentence].
```
Example: "Stop filling buyer details on every portal. Our agent handles it — automatically, in seconds. One click, done."

### The "While You Sleep" Pattern (always-on)
```
[Time when they can't work]. [What's happening].
[Product] [action] — [time], [day], [occasion].
[They] never [negative outcome] again.
```
Example: "2am on a Sunday. A customer needs a quote. Your assistant replies instantly. You never lose a sale to a slow reply."

## CTA Button Text

### High-intent (ready to buy)
- "Start free trial"
- "Get started free"
- "Try [product] free"

### Medium-intent (interested but cautious)
- "See it in action"
- "Get your [thing] set up"
- "Talk to our team"

### Low-intent (just exploring)
- "Join waitlist"
- "Get early access"
- "Learn more"

### Urgency CTAs
- "Get started now"
- "Don't lose another [customer/hour/sale]"
- "Start saving [time/money] today"

## FAQ Objection Handling

Structure each FAQ answer to: acknowledge concern → resolve it → end with a positive.

### Common objections and response patterns:

**"Is this hard to set up?"**
→ "[Timeframe] setup. [What you handle]. [They do almost nothing]."

**"What if it gets something wrong?"**
→ "[Safety mechanism]. [How handoff works]. [They stay in control]."

**"Can I change things later?"**
→ "Anytime. [How easy]. [Timeframe for changes to take effect]."

**"What if I want to stop?"**
→ "Cancel anytime. No lock-in. [What happens when they leave]. [We earn their business]."

**"Is my data safe?"**
→ "Your data stays [scope]. We never [bad things]. [Positive trust statement]."

**"Will people know it's AI?"**
→ "[How natural it sounds]. [Most don't notice]. [Transparency when asked]."

## Social Proof Patterns

### Metric-First
```
"We [had problem with number]. Now [improved number]."
— [Role], [Location]
```

### Comparison-to-Hiring
```
"[People] think I [hired/expanded]. I didn't. I just [what they did]."
— [Role], [Location]
```

### Before/After
```
"Before: [pain]. After: [outcome]. [Timeframe]."
— [Role], [Location]
```

## Pricing Comparison Pattern

Two-column layout. Status quo (left, red/warning) vs. product (right, green/positive).

```
Left column: "[Current approach]"
- x [Cost]
- x [Limitation 1]
- x [Limitation 2]
- x [Limitation 3]

Right column: "[Your product]"
- ✓ [Cost advantage]
- ✓ [Advantage 1]
- ✓ [Advantage 2]
- ✓ [Advantage 3]
```

Footer: "No [charge type]. No [commitment]. Cancel anytime."
