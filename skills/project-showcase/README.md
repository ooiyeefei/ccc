# project-showcase

A skill for adding a **filterable, project-based showcase catalog** to a site — the pattern where every project is one card that opens a detail page, and visitors filter by the **kind** of project (product / hackathon / R&D), not by tech stack.

It **interviews you first** — your framework, any existing project data, your own categories, and what media you have — before writing anything. Then it builds the gallery, the concise cards, and the rich detail pages in your site's own design system.

- **`SKILL.md`** — the procedure: interview → data model → build → verify.
- **`references/schema.md`** — the data model + the `trackOf()` derivation (so adding the filter doesn't force editing every old entry).
- **`references/patterns.md`** — card vs detail split, the filter bar, embedding video/images/slides, and the writing rules.

Designed to be user-invoked when you want to build or extend a projects/portfolio page. It surfaces sensible defaults but confirms your categories rather than assuming them.
